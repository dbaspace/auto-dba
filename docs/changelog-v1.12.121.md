# KeePlus / auto-dba v1.12.121

相对 [v1.12.120](changelog-v1.12.120.md)。从监控同步主机时会补上后加的标签，实例总览的主机列表默认每页 10 条。无 Agent 协议变更。无表结构变更。

## 主机同步

- 「从监控同步」不再只在主机标签为空时整份写入。按键合并：主机没有的键补上，两边都有且值不同时用监控的值，只在主机上的键保留。
- 已匹配到环境时，`idc` 固定为该环境编码，不跟监控里的 `idc` 走。区域和环境仍只补空项。

## 实例总览

- 主机列表默认每页 10 条，可选 10、20、30、50、100。其它引擎仍默认 20 条。切换到主机页时分页从第一页重新计。

## 打包与发版

```bash
STAMP=v1.12.121 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.121 -m "v1.12.121"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，已下发的 Agent 不必为这个版本重装。主机标签和总览分页要使用本版平台进程与前端，请重启平台并刷新页面。补标签需再点一次「从监控同步」。
