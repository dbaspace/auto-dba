# KeePlus / auto-dba v1.12.118

相对 [v1.12.117](changelog-v1.12.117.md)。资源配置里的主机按连接地址去重，并按云主机内网地址关联云资源。数据查询的复制和粘贴可以正常使用。无 Agent 协议变更。无表结构变更。

## 主机去重

- 连接主机是主机的唯一地址。比较时取逗号分隔的第一段，去掉端口，不区分大小写。这条规则跨全部租户，数据库实例不受影响。
- 新建主机时，地址已登记则补到原记录的空项，不再插入新行。原记录属于其它租户时拒绝。把地址改成另一台已登记主机的地址时拒绝保存。
- 「从监控同步」和云主机同步前会合并已有的重复主机：云实例 ID、环境、区域更全的那条留下，其余用来补空项。挂在重复行上的云清单改挂到留下的那条，然后删除重复行。仍被 Agent 或集群节点按 ID 引用的行不删，并在同步结果里列出。

## 云主机

- 云资源里对云主机点「立即同步」，只保留内网地址已经登记为主机的云机器。对不上的不入库，该账号下已有的多余云主机行会清掉。拉取失败的地域保留原数据。PostgreSQL、MySQL、Redis 仍同步全量。
- 命中的云主机挂到对应主机，并补齐云厂商、云实例 ID 和云 Region。
- 主机编辑页显示云厂商、云账号、云实例 ID、云 Region 和「同步云资源」。腾讯云主机的占位是 `ins-xxxx`。保存时只有 PostgreSQL 必须填写云实例 ID 和云 Region。

## 数据查询

- 查询编辑器里 Ctrl+C、Ctrl+X、Ctrl+V 按选区复制、剪切和粘贴，不再被高亮层挡住。
