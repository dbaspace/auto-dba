# KeePlus / auto-dba v1.12.135

相对 [v1.12.134](changelog-v1.12.134.md)。会话服务暂时不可用时不再把人登出；StarRocks 集群部署不再为同一台 FE 重复登记实例；域名管理各类型都显示创建时间，新建行排在最前。无表结构变更，无 Agent 协议变更。

## 登录

- Redis 暂时不可用时，鉴权返回 503，code 为 `session_unavailable`。登录过期和会话被踢仍是 401。
- 前端只在会话过期、被踢或 token 本身无效时清除登录。503 保留当前 token，并提示稍后重试。

## 权限申请

- 加载实例、域名或库失败时，选择区显示接口返回的原因。
- 加载成功且还没有选择库时，右侧仍显示「暂无已选数据库」。

## StarRocks 实例

- 集群部署登记实例时，本租户没有匹配行，会按 FE 地址和查询端口在全部租户里查找。实例主机和 FE 主机两边都做解析，IP 和域名算同一台。
- 找到已有实例就补上 `sr-cluster=` 标签，不再新建，也不改所属租户。同步结果会说明关联的是其它租户的已有实例。
- 查询端口不同的行不会合并，例如 `8030` 和 `9030`。已经多出来的行不会自动删除。

## 域名管理

- PostgreSQL、Redis、主机、StarRocks、ClickHouse、Kafka 和「其他」共用同一张列表，都显示「创建时间」。
- 列表按创建时间从新到旧排列。任一类型点一键同步后回到第 1 页，这次新建的行出现在该类型最前面。
- 再次同步只更新的旧域名保留原来的创建时间，不会因为又同步一次跑到前面。

```bash
# 本地标签（本发版未 push / 未发 GitHub Release）：

```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。登录、StarRocks 登记和域名列表要使用本版平台进程，请重启平台。已有元库不用补表。
