# KeePlus / auto-dba v1.12.126

相对 [v1.12.125](changelog-v1.12.125.md)。工单待审批通知的发送结果写入查询审计，飞书发送失败会重试一次。云资源增加 Kafka，云同步按账号并行并区分跳过与失败。无表结构变更，无 Agent 协议变更。

## 工单通知

- 工单创建、转审批人、退回待审批时，邮件和飞书按人和渠道各记一条查询审计。类型为「通知」，可按工单号查看成功、失败和跳过原因。
- 多个审批人会拆开分别通知，用户名查找不区分大小写。
- 飞书 token 失效会重新取一次再发；网络错误或接口 5xx 等 1 秒重试一次。接收人不在应用可用范围时，失败原因写明 `230013`。
- 工单链接仍是本机地址时，日志和审计会提示在邮件设置填写前端访问地址。

## 云资源

- 云资源增加 Kafka，可查看清单并提交云 Kafka 变更。定时同步任务名称改为包含 Kafka。
- 多个云账号并行同步。单个引擎超过 4 分钟记为超时。未勾选定时同步的引擎记为跳过，不再沿用上一次成功状态。上一轮还在执行时不记失败。连续失败会打出云资源同步告警。

## 打包与发版

```bash
STAMP=v1.12.126 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.126 -m "v1.12.126"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。工单通知审计和云 Kafka 要使用本版平台进程与前端，请重启平台并刷新页面。
