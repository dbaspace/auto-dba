# KeePlus / auto-dba v1.12.92

相对 [v1.12.91](changelog-v1.12.91.md)。工单执行和审核按域名管理拨号；同步槽采集改用实例标签里的域名；云资源列表展示内网地址；CDC 草稿恢复后停在原来的步骤。无 Agent 协议变更，无表结构变更。

## 工单拨号

- DDL、DML、DQL 导出、建库和 Redis 工单的拨号地址只来自域名管理。页面已选定的域名直接用。没选时，该实例在域名管理里只有一条地址就用那条；没有或多条则失败，不再回退连接主机。
- MySQL 的 goInception 审核同样按这条地址连库。
- 数据导出的数据源改为当前环境、当前引擎下的域名。库下拉不再重复拼接域名。

## 同步槽

- 采集复制槽时只读实例标签 `domain=`，用这个地址拨号。没有该标签的实例跳过，并在采集结果里说明原因，不使用连接主机。

## 云资源

- 云 PostgreSQL、MySQL、Redis、云主机列表在云实例后展示内网地址。地址从已同步的原始返回解析：PostgreSQL 取内网地址和端口，MySQL 取 Vip，Redis 取对照用的地址，云主机取内网地址第一段。解析不到显示空。搜索可以按这个地址过滤。
- 「立即同步」改为在按钮旁选择云账号，不再弹出独立对话框。

## CDC

- 打开创建页时，草稿恢复完成前不再把空表单写进本地草稿。恢复后停在草稿记录的步骤，并按已填源端补拉库表。源端域名对不上时，下拉保持未选，任务名、环境、步骤、已选表和目标端保留。
