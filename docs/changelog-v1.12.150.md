# KeePlus / auto-dba v1.12.150

相对 [v1.12.149](changelog-v1.12.149.md)。拓扑视图按数据库筛选可以全选和反选。无 Agent 协议变更，无表结构变更。

## SQL 洞察

- 「数据库」筛选增加「全选」和「反选」。全选勾选当前搜索结果；反选把当前结果里已勾的取消、未勾的勾上。不在这次搜索结果里的已选库保持不变。没有输入时，这两个操作作用于全部库。清空仍取消全部已选。

## 打包与发版

```bash
STAMP=v1.12.150 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.150 -m "v1.12.150"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。归档仍依赖 v1.12.145 起的 SQL 执行器；执行器已是 v1.12.145 或本版包时，不必为这个版本重装。若执行器仍是 v1.12.144 及更早，须用 v1.12.145 或本版包重下发。其它 Agent 若仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。本版拓扑筛选要使用本版平台进程，请重启平台。
