# KeePlus / auto-dba v1.12.141

相对 [v1.12.140](changelog-v1.12.140.md)。登录会话能看出人是否还在用。工作台待办标题不再被整段原因撑开。无 Agent 协议变更。

## 登录会话

- 会话列表增加使用状态和最近操作。最近 15 分钟内有页面操作或 PAT 调用记为使用中，否则为离开。
- 页面在鼠标、键盘、滚动时约每分钟上报一次活动时间。这次上报不延长会话过期，也不重置闲置退出。
- 没有浏览器会话、但 PAT 仍在近期调用的用户，以 PAT 行出现在第一页。这类行不能踢会话。没有过期时间的 PAT 显示为不过期。

## 工作台待办

- 待办标题改为工单号、库名和原因的第一行开头，原因最多 40 个字。长描述不再把表格撑出一行。

## 打包与发版

```bash
STAMP=v1.12.141 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.141 -m "v1.12.141"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。登录会话的使用状态要使用本版平台进程，请重启平台。
