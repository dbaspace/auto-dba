# KeePlus / auto-dba v1.12.154

相对 [v1.12.153](changelog-v1.12.153.md)。归档按执行记录统计，查询脱敏改到专用页并按原字段匹配。全局参数里已有专门入口的密钥、调度、OSS 和水印不再在这里改。

## 归档

- 任务列表的查看、编辑、执行、停止、启用改为图标，点击、禁用和确认与原来一致。
- 成功率和今日完成、今日失败按执行记录计算。删除 0 行仍算成功。没有已结束的执行时成功率显示为「-」。
- 归档报表的今日、本周、本月按执行时间过滤。明细展示执行状态和执行时间。

## 查询脱敏

- 「敏感数据脱敏」移到配置中心 → 基础设置。可自定义列名，并有启用开关。关闭时保留列名但不脱敏。
- 按 SELECT 的原字段脱敏，不按 AS 后面的别名。`t.mobile`、`mobile AS mob` 都按 `mobile`。`mob AS mobile`、`1 AS mobile` 不脱敏。大小写不区分，`card` 能匹配 `carD`、`Card`。
- 开关关闭或没有列名时不解析 SQL。解析失败时退回按结果列名匹配，查询本身不失败。仍只作用于查询结果，导出和归档不脱敏。

## 全局参数

- 定时任务的开关和 Cron 只在定时任务里改，SQL 洞察设置不再列出这些项。
- 云厂商 AK/SK、腾讯云默认地域和地域映射不再在全局参数修改。密钥用云账号，地域用实例云地域；云账号只有一个地域时也可作为兜底。库里已有的 `ap-beijing` 仍是最后兜底。
- 云日志回溯、限速、API 间隔允许写成 0。增量包上限和尝试次数必须大于等于 1。
- 迁移 OSS 的地址、桶、密钥和分片只使用配置中心的对象存储。只填过全局参数的环境，需要按环境重新录入后，OSS 中转才会继续可用。
- 用户水印改到系统通知，开关为「开启用户水印」。

## 页面加载

- 发版后如果浏览器还在要已经不存在的分包，自动刷新一次。

## 打包与发版

```bash
STAMP=v1.12.154 ./scripts/pack_release.sh all
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，不必仅为本次重下发执行器。归档统计、脱敏、全局参数收口和水印在平台侧，请重启平台。

元库在重启时为系统通知补水印列。跳过全量迁移的已有库可先执行：

```sql
ALTER TABLE tbl_system_notices ADD COLUMN IF NOT EXISTS user_watermark_enabled INTEGER NOT NULL DEFAULT 0;
```
