# KeePlus / auto-dba v1.12.114

相对 [v1.12.113](changelog-v1.12.113.md)。SQL 洞察的页签按角色分开授权。角色授权里去掉「同步云慢日志」。工单在执行前拒绝只有列清单的 `INSERT`。无 Agent 协议变更。无表结构变更。

## SQL 洞察

- 8 个页签各自一条权限，挂在「SQL 洞察」下面：SQL洞察、洞察分析、可视汇总、AWR报告、表空间分析、智能分析、云慢日志、同步监控。角色勾上的才展示，没勾的不出现。只开通页面、不勾页签时，页面能进，页签栏为空。
- 已经有 SQL 洞察页面的角色，首次启动会带上这 8 个页签。之后取消某一项会保留。平台管理员和租户管理员仍能看到全部页签。
- 各页签的读接口按同一条权限校验。手动采集、生成 AWR、采集表空间、智能分析仍用原来的操作权限。
- 去掉「同步云慢日志」菜单和手动同步接口。慢日志仍由定时任务每 5 分钟拉取。云 PostgreSQL 页上的「立即同步」仍是同步云实例清单。

## SQL 工单

- 审核和执行都会拒绝只有列清单、没有 `VALUES` 或 `SELECT` 的 `INSERT` / `REPLACE`。执行在连接数据库之前返回「第 n 条是不完整的 INSERT」。
- 列清单后已经写了 `VALUES` 或 `SELECT` 的语句不拦截。
