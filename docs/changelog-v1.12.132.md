# KeePlus / auto-dba v1.12.132

相对 [v1.12.131](changelog-v1.12.131.md)。云 Kafka 列表同步并展示主题、分区、磁盘、版本、集群类型和内网地址。无表结构变更，无 Agent 协议变更。

## 云 Kafka

- 同步时对每个实例补查属性。磁盘优先用属性里的容量，为 0 时用动态磁盘配额，写入原来的磁盘列。某一个实例查属性失败时保留清单里已有的数，并记入同步结果，不中断整批同步。
- 列表增加 Topic 上限、Topic 使用、分区上限、分区已用、版本、集群类型。Topic 使用优先取已创建主题数，没有时用清单里的 TopicNum。
- 内网地址先用 Vip，没有时用 VipList。端口为空时写成 9092。
- 集群类型与腾讯云控制台一致：`profession` 显示专业版，`premium` 显示高级版，`standard` 显示标准版。
- 云 Kafka 不再展示规格列。PostgreSQL、MySQL、Redis 和云主机的规格列不变。
- 已有实例的配额和磁盘要等下次云 Kafka 同步后才完整。版本和内网地址若原始数据里已有，重启平台并刷新后即可显示。

## 打包与发版

```bash
STAMP=v1.12.132 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.132 -m "v1.12.132"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。云 Kafka 列表要使用本版平台进程，请重启平台。已有元库不用补表。
