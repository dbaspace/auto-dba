# KeePlus / auto-dba v1.12.81

相对 [v1.12.80](changelog-v1.12.80.md)。启动时自动补迁移任务的源端、目标端环境列，并把旧任务的环境写到两端。无 Agent 协议变更。

## 数据库查询

- 收藏改为按名称保存。点「收藏」弹出创建窗口，可自己起名；同名则更新这一条。已收藏的页签显示「更新收藏」「另存为」和收藏名，不再显示「收藏」。
- 打开收藏时，左侧库树会展开并定位到对应库。
- 查询页签可以拖动换顺序，双击标题改名。已收藏的页签标题用收藏名。页签上不再显示打开时间。
- 选中一段 SQL 执行后，这段文字保持选中。`⌘/Ctrl+Shift+Enter` 只执行选中内容。从这次结果导出时，导出页只带这句已执行的 SQL。
- 查询结果里的时间按列类型展示：日期时间用 UTC 微秒加 `Z`，日期只显示日期，时间只显示时刻。

## 云资源

- 云 PostgreSQL、云 MySQL 等页签不再和资源配置里的同名页签混在一起。
- 云资源列表可按名称、实例 ID、账号、状态、地域搜索，默认每页 10 条，可改为 10、20、30、50、100。
- 一个云账号的同一对 AK/SK 可登记多个地域，同步时这些地域并行拉取。

## CDC

- 初始化任务的 publication 与 Debezium connector 同名，默认 `rt_{环境}_{库名}`，提交前可以改 publication。Slot 为 `slot_{环境}_{库名}_{6位}`。
- 分库在默认开关下按每个有表的物理库拆成单独的初始化任务；汇总任务不再出现在默认列表里。加表仍只追加表，不新建 publication 和 slot。

## 迁移与账号

- 新建迁移任务分别选择源端环境和目标端环境，地址列表按各自环境过滤。
- StarRocks 账号权限保留 DDL、导出；其它引擎提交时去掉这两项。
