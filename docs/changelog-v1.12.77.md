# KeePlus / auto-dba v1.12.77

## CDC 加表：跨租户审核人与已授权父任务

CDC 任务在大数据租户、源库和域名在订单租户并已授权给大数据时，加表不再要求审核人必须是任务租户成员。

- 审核人可为：任务租户活跃成员；源库/域名/实例归属租户的活跃成员（且该资源已 grant 给任务租户）；超级用户。
- 超级用户：平台管理员、全局参数 `sync_default_approver`、`dba` 租户活跃成员。这三类不受实例/库审批人名单拦截，可当人和工单的审核人。
- 加表任务与工单仍挂在父任务租户。
- 资源归属租户只能看到并提交「源资源归自己且已授权给任务租户」的 init 父任务。未授权租户仍不可提交。
