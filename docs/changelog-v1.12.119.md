# KeePlus / auto-dba v1.12.119

相对 [v1.12.118](changelog-v1.12.118.md)。查询结果的过滤和每页条数可以正常使用，同步列表的实例地址改为任务源端。无 Agent 协议变更。无表结构变更。

## 数据查询

- 结果搜索词和当前页记在各自的查询窗口上。输入过滤后切到另一个窗口再切回来，过滤词和页码还在。
- 在该窗口重新执行、查询失败，或切换同一窗口里的「查询 #1 / #2」时，清空该窗口的过滤和页码。
- 「条/页」下拉改挂到页面外层，不再被结果栏裁成只剩「10 条/页」。可选 10、20、50、100，选中后仍记在本地。

## 同步列表

- 实例地址优先显示 CDC 任务的源端地址和端口。任务里没有源端时，显示槽采集到的连接主机。采集、重启和删除仍按槽的连接主机查找。
- 不再用已登记库的绑定域名填充这一列。

## 打包与发版

```bash
STAMP=v1.12.119 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.119 -m "v1.12.119"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，已下发的 Agent 不必为这个版本重装。查询过滤和同步列表地址要使用本版平台进程与前端，请重启平台并刷新页面。
