# KeePlus / auto-dba v1.12.133

相对 [v1.12.132](changelog-v1.12.132.md)。表空间手动采集只扫当前实例；登录会话改为每个东八区自然日最多延长一次；主机终端增加 8 小时绝对上限。无表结构变更，无 Agent 协议变更。

## 表空间采集

- 手动采集、暂停、恢复、取消同时接受 URL 参数和 JSON。页面已选实例时只采这一台，不再因为实例 ID 在请求体里被丢掉而去扫全部 PostgreSQL。
- 库范围随页面选择：仅集群级不扫库，指定库只扫该库，扫描全部库仍只扫当前实例。定时全量采集不变。
- 「手动采集」只在提交时转圈。进度在采集任务抽屉里，按已完成实例和库数计算，并显示当前实例、当前库、阶段和失败原因。
- 单实例采集超过 3 分钟记为失败，并写明停在哪个库。
- 大表统计改为从 `pg_statio_user_tables` 读取 `heap_blks_read` / `heap_blks_hit`。原先查 `pg_stat_user_tables` 的这两列，采集 SQL 会失败。

## SQL 洞察

- AWR 报告列表在今天没有报告时，说明每日报告在次日生成，并提示把时间范围包含昨天。其它空范围只说明该时段没有报告。
- 智能分析的结论、原因和建议按结构化字段展示，不再把对象直接显示成 JSON。

## 云 MySQL

- 同步时用云监控补磁盘占用量。某一实例查不到时保留上次结果，不把已有用量清掉。
- 云 MySQL 列表增加「使用存储」，显示占用和相对磁盘容量的百分比。其它引擎的列不变。已有实例要等下次云 MySQL 同步后才有用量。

## 登录会话

- 仍有效的会话每个东八区自然日最多延长一次，窗口从当天第一次仍有效的访问起算。超过过期时间没有再访问则要重新登录。
- 同一天内再次打开页面不再把过期时间反复推后。

## 主机终端

- 无输入且无输出仍按空闲上限断开，有键盘输入或终端输出会续期。
- 自打开终端起最长 8 小时，到点即使仍在操作也断开。可在 `terminal.max_absolute_sec` 调整，默认 28800 秒。
- 终端 SSH 保活次数从 3 改为 10。脚本在平台发布包内，重启平台后生效，不必重下发 Agent。

## 慢日志总线

- 连不上总线时提示连接超时和未写入条数，不再只留下底层拨号错误。
