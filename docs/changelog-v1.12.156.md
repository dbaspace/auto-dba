# KeePlus / auto-dba v1.12.156

相对 [v1.12.155](changelog-v1.12.155.md)。定时任务按分组查看，执行历史可以翻页。

## 定时任务

- 平台任务按已有分组分段展示：调度扫描、工单、采集、告警、云资源、CDC、DNS、会话、安全。默认「全部」仍能看到各组。
- 选中某一个分组时，不再在表上方重复显示分组名和数量。
- 执行历史默认每页 10 条，可改为 10、20、30、50、100。按页向接口取数，并显示总条数。
- 历史表按抽屉宽度排开，「耗时ms」完整显示，不再出现横向滚动条。

## 打包与发版

```bash
STAMP=v1.12.156 ./scripts/pack_release.sh all
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，不必仅为本次重下发执行器。定时任务展示和历史分页在平台侧，请重启平台。
