# KeePlus / auto-dba v1.12.151

相对 [v1.12.150](changelog-v1.12.150.md)。拓扑视图按 Pod 展示最近 7 天的 HikariCP 连接池用量，并给出一句分析。无 Agent 协议变更，无表结构变更。

## SQL 洞察

- 拓扑表在 Pod 后展示连接池最新值：当前、活跃、空闲、等待、最大、最小，以及 7 日活跃峰值、7 日等待峰值和分析。数据来自 Prometheus 最近 7 天、步长 15 分钟的区间查询，按 Pod 名对齐。同一 Pod 多个池先按时刻求和。查不到池指标时这些列留空，连接行照常返回。
- 分析按 7 天曲线写一句话：曾打满并等待、等待但未满、活跃接近上限、长期空闲、此刻空闲用完，或未接近上限。点「查看分析」弹出全文。
- 表格和导出不再展示命名空间、节点。Pod 列固定宽度，过长的名字截断，点「查看」显示完整名称。导出仍包含完整分析和 Pod 名。

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。归档仍依赖 v1.12.145 起的 SQL 执行器；执行器已是 v1.12.145 或本版包时，不必为这个版本重装。若执行器仍是 v1.12.144 及更早，须用 v1.12.145 或本版包重下发。其它 Agent 若仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。本版拓扑连接池要使用本版平台进程，请重启平台。
