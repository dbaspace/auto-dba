# KeePlus / auto-dba v1.12.138

相对 [v1.12.137](changelog-v1.12.137.md)。同步列表不再把 CDC 任务正文整段读进平台。登记已有 StarRocks 集群时，目录按每台 BE 回填，FE 软件根无法确定时不写入。无 Agent 协议变更。

## 同步列表

- 打开同步列表时，只取出槽名配对和连接回退需要的字段，不再把 debezium 配置和表清单读进平台进程。
- 采集、重启仍使用完整任务正文。列表上的槽名、连接器、主题和源地址配对方式不变。
- 平台启动时在元库创建函数 `cdc_list_extra`。这不是表结构变更，重启平台后由迁移自动建好。

## StarRocks 目录探测

- 登记已有集群时，每台 BE 各自读取 `:8040/varz`，软件目录和数据目录按主机回填。各台不一致时，集群级目录留空。
- FE 软件根以 `meta_dir` 为准。日志目录优先读 `sys_log_dir`，没有再读 `internal_log_dir`。3.2 的配置列按 Key、AliasNames、Value 取值，不再把别名当成路径。
- 两条路径都对不上 `fe` 目录、又不是全局默认时，不写入软件目录，避免升级替换错目录。末段已是 `dorisdb_base` 的安装根不再被更深的旁路路径覆盖。
- 探测到的目录与全局默认相同时，节点上留空，继续走全局配置。探测超时改为 45 秒。

## 集群列表

- 集群页工具栏顺序为：环境、按名称搜索、刷新、新建集群、登记已有集群。筛选和搜索仍在当前列表里完成。
- 再次点击已打开的集群名称时，页面滚到该集群详情，不再收起。
