# KeePlus / auto-dba v1.12.134

相对 [v1.12.133](changelog-v1.12.133.md)。PostgreSQL 实例总览增加智能分析；SR 控制台样式打进发布包。无表结构变更，无 Agent 协议变更。

## PostgreSQL 智能分析

- 实例总览在 PostgreSQL 下增加「智能分析」。分析库文件增长、QPS、TPS、锁和 CPU，并单独保存报告。
- 与主机磁盘分析分开。两边可以各有一条进行中的任务，不再互相占用。
- 报告页标题为「智能分析报告」。主机磁盘报告仍用原来的标题。
- QPS/TPS 按每台实例自己的地址计算。满 3 天的区间用 15 分钟采样，短区间仍是 5 分钟。Prometheus 返回 HTML 错误页时，只提示网关超时或状态码，不再把整页 HTML 写进结果。

## 工作台

- 管理员工作台增加近 7 天查询审计统计。统计失败时显示「统计加载失败」，不再显示成「暂无查询审计」。

## 权限申请

- 平台管理员和超级审核白名单可以打开并批准其它租户的权限申请。登录名 admin 不必是资源所属租户成员。
- 管理员在租户模式下提交时，已对本租户可见的库不再被写成「实例未登记」。
- StarRocks 申请说明改为：账号不存在则建账号并通知密码，再按表、视图、物化视图和库分别授权。

## SR 控制台

- 一体包、后端包和 Docker 镜像带上 `assets/starrocks-webroot`。目录或样式文件缺失时打包失败。
- 用新包在包根启动后，BE 查询页会加载到本地 css/js。旧包没有这个目录，页面会是裸 HTML。

## 打包与发版

```bash
STAMP=v1.12.134 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.134 -m "v1.12.134"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。智能分析和 SR 控制台样式要使用本版平台进程，请重启平台。已有元库不用补表。
