## 1. 角色与入口

| 角色视角 | 典型职责 | 常用入口 |
|----------|----------|----------|
| 平台管理员 | 用户/角色/菜单、租户生命周期、进入租户审计、划拨资源 | 用户权限、租户管理 |
| 租户管理员 / DBA | 本租实例与库、审批人、工单审批、部署与告警 | 数据库配置、工单、集群部署、告警 |
| 开发者 | 提交工单、查询、查看授权资源 | 工单申请、数据查询 |

- 业务侧栏菜单由**当前租户成员角色**决定。
- 用户/菜单/LDAP/SSO 等平台治理菜单走**全局角色**（与当前租户无关）。
- 种子账号：`admin` / `admin123`（首次登录后请改密）。

---

## 2. 登录与选租户

1. 打开前端（开发常见 `http://127.0.0.1:5174`），选择认证方式：本地 / LDAP / SSO。
2. 登录成功后：
   - **仅一个租户成员**：直接进入工作台，JWT 带当前 `tid`。
   - **多个租户**：进入「选择租户」页，选定后进入。
3. 顶栏可切换租户（仅本人已加入且活跃的租户）。
4. LDAP / SSO **首次**登录：自动创建本地用户（默认角色 developer），并在尚无成员时加入**默认租户**；业务团队应再把用户加入对应业务租户（普通用户加入后会离开默认租户；平台管理员可同时保留默认租户）。

详见 [features.md · 登录与账号](features.md#登录与账号)。

## 3. 多租户使用

### 3.1 创建租户与加人

路径：**用户权限 → 租户管理**（`/config/tenants`）。

1. 新建租户（code 唯一，如 `abc`）。
2. **成员**：添加用户并绑定租户内角色（决定菜单与业务权限）。
3. 用户是平台级账号；同一人可加入多个租户，每次只活跃一个 `tid`。

### 3.1.1 删除租户

「更多 → 删除」。须同时满足：

1. 不是默认租户（`default`）
2. **无成员**
3. **未绑定业务资源**（实例、已登记库、工单、集群等）

有绑定资源时提示「需要先释放资源」——请先用审计划拨把资源迁走；仍有成员时提示先移除成员。停用（编辑状态为 `disabled`）可保留数据软退场，与硬删不同。

顶栏租户切换器展示当前租户的**名称**（非编码）。若删除的是当前会话租户，系统会自动切到仍可用的租户（优先默认租户）。平台管理员创建业务租户后仍保留默认租户成员，避免顶栏只剩业务租户名称。

### 3.2 实例与库的归属

| 对象 | 说明 |
|------|------|
| 实例 | 落在登记时的当前租户；同 host:port 不同租户可各有一份 |
| 已登记库 | 默认同实例租户；可**单独指定归属租户**（共享实例、业务库归业务方） |
| 账号 | 随库走 |

日常：在目标租户下登记实例/库；需要「地址在基础设施租户、库归业务租户」时用审计划拨（见下）。

### 3.3 可见范围（全局 / 私有）

登记实例或库时：

| 范围 | 效果 |
|------|------|
| **全局** | 本租户成员可见 |
| **私有** | 仅「可访问用户」或「绑定角色」命中者可见；同租未命中则不可见 |

- 可访问用户 / 审批人 / 绑定角色的候选项**只能是本租成员**；异租用户无法靠填名单跨租访问。
- 跨租只读请用 **跨租户授权（grant）**，不要往私有名单里填外租用户。
- 平台特权角色（admin / dba / operator 等）可旁路 private。

### 3.4 跨租户授权（grant）

路径：租户管理 → 某租户「授权」。

1. 资源方 = 点授权的那个租户。
2. 选择类型（实例 / 已登记库 / 域名 / SR 集群 / 部署集群）→ 下拉选资源 → 选目标租户 → 授权（只读）。
3. 下方表格是**已有授权记录**，不是资源目录；空表表示尚未授权过。

### 3.5 平台审计与划拨

仅平台管理员 + 审计会话（`impersonate`）：

1. 租户管理 → 进入某租户「审计」。
2. 此时实例/库/域名列表为全平台视野，带「所属租户」。
3. **指定实例租户**：整实例及同租下属库、账号、域名迁到目标租户（异租库不覆盖）。
4. **指定库归属 / 批量指定租户**：只改库与账号 `tenant_id`，**不迁实例**（适合共享实例）。
5. **域名管理**：先「一键同步」（可按类型 Tab 过滤）；再单条或**批量指定租户**。同步按 `db_type` 隔离，不会把 MySQL 域名写到 PG。
6. 集群、代理等同理，见 [tenancy.md](tenancy.md)。

注意：划拨**不改**实例密码；测连/查询解密失败时到「实例」页重填密码（常见原因是服务加密密钥变更，与划拨无关）。

### 3.6 删除用户

删除用户会清理其租户成员与按用户的 grant，避免成员列表出现空白幽灵行。删前确认业务租户内已无必要归属。

## 4. 资产登记（工单前置）

路径：**数据库配置**（侧栏「资源配置」）。

1. **实例管理**：登记连接（类型、域名/地址、账号密码、审批人、可见范围）。实例可登记多个域名，工单数据源按域名展开选择。列表支持按列排序与底部分页（默认每页 10 条）。
2. **已登记库**：绑定实例、库名、审批人、可见范围，并从实例域名中勾选该库可用的 `domains`；工单目标必须已登记。
3. **域名管理**：从各类型实例同步访问域名；新域名默认进默认租户；按类型隔离后可划拨给业务租户。Redis 查询侧栏按环境→域名展开。
4. **账号管理**：供权限类工单使用。

约束：未登记库 / 非审批人提交工单会失败，并返回可读错误。DDL/DML/建库/权限申请须选择实例域名；库列表按所选域名过滤，执行连接使用该域名。

## 4.1 CMDB 日常操作

路径：顶栏 **CMDB**。写入真相源仍是实例/库等业务表；CMDB 是统一目录与关系门面。详见 [cmdb.md](cmdb.md)。

| 操作 | 入口 | 说明 |
|------|------|------|
| 查资产 | 资产目录 | 按类型筛选；可看健康徽章（无库登记 / 无审批人）；`app=` / `biz=` 业务标签聚合 |
| 看拓扑 | 关系拓扑 | 填 CI ID，深度 1–3，可按关系类型过滤；展示租户 |
| 影响分析 | 拓扑页 / 资产详情 | 「下游影响」回答改实例/库会波及谁；告警详情也可「查 CMDB 影响」 |
| 发现补登 | 发现登记 | 监控候选、集群/HA 候选、Live 库登记；查看质量概览与配置漂移 |
| 快照基线 | 资产详情 | 对实例/库拍快照或设基线；更新业务数据时自动追加快照 |
| 标签 / 同步 | 标签管理、同步任务 | 外部同步默认只出候选（`cmdb_sync_auto_apply=false`） |

业务映射约定：实例/库标签写 `app=业务名` 或 `biz=业务名`，资产页用「业务标签」框查询；也可手工建 `belongs_to_app` 关系。

## 5. 工单操作

1. 在目标租户下，从侧栏进入 DDL / DML / DQL / 建库等申请页。
2. 选择环境与实例类型后，在「数据源」中按**域名**选择（非 host）；再选已登记库、填写审批人与 SQL/说明，提交。
3. 审批人在工单列表或待办中通过/驳回；通过后后台执行（大结果会收敛展示）。
4. **更换审核人**（仅提交者、待审批）：详情页「更换审核人」；新人须为本租成员且在审批人列表中。后端优先按工单绑定的 `database_id` 校验审批人。详见 [ticket-assignee-transfer.md](ticket-assignee-transfer.md)。
5. 超级审核白名单：全局参数 `issue_global_approver_whitelist`（可批任意 pending，不能代人更换审核人）。

## 6. 数据查询

路径：**数据查询**（库 / Kafka / Redis）。

- 仅对当前租户可见（或 grant 只读）的已登记目标执行。
- 语句写入查询审计；注意权限与私有库可见性。

## 9. 集群部署与高可用

1. **集群部署** Hub：按引擎进入 StarRocks / MySQL·PG·Redis / 代理工作台。
2. 节点需登记对应 Agent（Node Agent / 平台 Agent），再做预检与变更。
3. **高可用服务维护**：与「集群部署」职责不同（切换/维护 vs 装机扩缩）。

见 [sr-cluster.md](sr-cluster.md)、[db-cluster.md](db-cluster.md)、[ha.md](ha.md)。

## 10. 认证与配置中心

| 配置 | 路径 | 说明 |
|------|------|------|
| LDAP / SSO / 邮件 / 通知 | 认证配置 | SSO 回调须与 IdP 白名单一致；更换 `jwt_secret` 后需重存 Client Secret / LDAP Bind 密码 |
| 全局参数 | 配置中心 | 审批开关、空闲登出、白名单等 |
| 区域 / 环境 | 配置中心 | 业务标签；**不是** Nacos Namespace |
| 对象存储 / Agent | 配置中心 | 迁移中转、备份、下发 |

生产敏感配置（DSN、JWT、SSH 私钥）建议放 **Nacos**，本地只留引导：见 [nacos-config.md](nacos-config.md)。

## 11. 常见问题

| 现象 | 处理 |
|------|------|
| 登录后进不了业务页 / 要求选租户 | 确认已被加入至少一个活跃租户；多租时完成选择 |
| 侧栏菜单不对 | 检查**当前租户**成员角色，不是全局用户角色 |
| 私有库看不见 | 是否在可访问用户/绑定角色中；或改为全局 |
| 异租用户加不进审批人 | 正常：须先加入该库所属租户 |
| 更换审核人失败 | 是否提交者、是否 pending、新人是否在库审批人且为本租成员 |
| 审计划拨后测连密码错 | 到实例页重填密码（密钥不一致）；划拨不改密文 |
| SSO 换票 Secret 解密失败 | 认证配置中重新保存 Client Secret |
| 跨租 Get 404 | 预期；用 grant 或审计，不要猜 ID |
| 生产域名白屏、`/assets` 404 或 `404 Route Not Found` | 见 [faq-spa-white-screen.md](faq-spa-white-screen.md)（网关路由 / 缓存 / `serve_static`） |
| 删除租户失败「需要先释放资源」 | 进入审计划拨实例/库/集群后再删；或先移除成员；见 §3.1.1 |
