# KeePlus / auto-dba v1.12.82

相对 [v1.12.81](changelog-v1.12.81.md)。无 Agent 协议变更。

## 数据库查询

- 「运行」和 `⌘/Ctrl+Enter`：窗口里有多条 SQL，并且这一次确实选中了一段时，只执行选中内容；否则执行整段。不再沿用上一次留下的选区。`⌘/Ctrl+Shift+Enter` 仍是必须有选中才执行。
- 左侧搜索数据库时，正在输入的库名不会被当前页签清掉。只有换到另一个库、并且现有搜索或环境过滤把该库藏起来时，才清空过滤并在树上定位。
- 打开收藏或查询历史后，清掉旧选区和上一份结果。再点「运行」执行刚打开的全文，并进入加载。没有 SQL 时提示「请先输入 SQL」。库不在当前目录里时，结果区留下「未找到库」。目录还在加载时，等加载完再打开。
