# KeePlus / auto-dba v1.12.125

相对 [v1.12.124](changelog-v1.12.124.md)。执行失败或已终止的工单改为退回待审批，不再直接重跑 SQL。SQL 洞察里的「SQL洞察」页签改名为「快照查询」。无表结构变更，无 Agent 协议变更。

## 工单

- 执行失败、已终止时，按钮由「重试执行」改为「重新审批」。确认文案为「将退回待审批，不会再次执行」。
- 新接口 `PUT /tickets/:id/reopen` 只把工单状态改回待审批，保留上次执行结果，不会再次执行 SQL。
- 审批人再次通过后，仍走现有批准流程才会执行。
- 已通过、尚未执行的「立即执行」不变。

## SQL 洞察

- 页内页签「SQL洞察」改名为「快照查询」。页面标题和顶部入口仍是「SQL 洞察」。

## 打包与发版

```bash
STAMP=v1.12.125 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.125 -m "v1.12.125"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。工单退回待审批要使用本版平台进程与前端，请重启平台并刷新页面。
