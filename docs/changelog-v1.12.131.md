# KeePlus / auto-dba v1.12.131

相对 [v1.12.130](changelog-v1.12.130.md)。工单创建和审核人更换时，邮件报错、卡住、未就绪或异常都不再挡住飞书、企微和群机器人。无表结构变更，无 Agent 协议变更。

## 工单通知

- 邮件在单独的流程里发送。飞书、企微、群机器人不等邮件结果，各自写审计。
- 邮件认证失败、连接被拒绝、收件人被拒，只记邮件失败。SMTP 未就绪也只记邮件失败。
- SMTP 建连最多 10 秒，连上后单封最多 30 秒。超时记为「SMTP 超时」。25、587 端口在服务器支持时仍走 STARTTLS，认证方式不变。
- 邮件发送过程中 panic 时记「邮件发送异常」，不影响其它渠道。
- 工单链接仍从邮件设置读取前端访问地址。读不到时用默认地址。

## 打包与发版

```bash
STAMP=v1.12.131 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.131 -m "v1.12.131"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。工单通知要使用本版平台进程，请重启平台。已有元库不用补表。
