KeePlus 模块关系图

KeePlus（工程入口 cmd/auto-dba）面向 DBA / 开发的运维自助工作台： 业务对象（实例、库、账号、审批人）登记在本系统内， 工单、查询、同步、迁移、闪回、归档、备份与诊断都围绕这些登记对象执行。 本页梳理前端、控制面、领域模块与外部系统之间的依赖关系。

工单闭环

提交 → 审核规则 → 审批 → 异步执行 → 通知；结果收敛后落库。

sequenceDiagram
  participant U as 用户
  participant FE as 前端
  participant API as Handler
  participant Check as sqlcheck
  participant Exec as ticketexec
  participant DB as 目标实例
  participant Mail as SMTP

  U->>FE: 提交工单
  FE->>API: POST ticket
  API->>Check: SQL审核
  Check-->>API: 通过或驳回
  API-->>FE: 待审批
  U->>API: 审批通过
  API->>Exec: 异步执行
  Exec->>DB: 执行DDL_DML等
  Exec-->>API: 收敛结果落库
  API->>Mail: 失败或待执行超时通知
