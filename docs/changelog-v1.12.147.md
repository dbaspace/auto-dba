# KeePlus / auto-dba v1.12.147

相对 [v1.12.146](changelog-v1.12.146.md)。SQL 洞察的拓扑视图可以按列排序、按数据库筛选，并导出当前结果。无 Agent 协议变更，无表结构变更。

## SQL 洞察

- 「数据库」「连接数」可点表头排序。连接数默认从多到少，再点一次改为从少到多。
- 「数据库」表头可搜索并多选库名，只看当前结果里选中的库。清空选择后仍显示全部。换实例后筛选清空。
- 「重置」右侧增加「导出」。导出当前筛选和排序后的全部行，列为客户端地址、数据库、连接数、Pod、命名空间、节点。没有查询结果时按钮不可用。

## 打包与发版

```bash
STAMP=v1.12.147 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.147 -m "v1.12.147"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。归档仍依赖 v1.12.145 起的 SQL 执行器；执行器已是 v1.12.145 或本版包时，不必为这个版本重装。若执行器仍是 v1.12.144 及更早，须用 v1.12.145 或本版包重下发。其它 Agent 若仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。本版拓扑排序、筛选和导出要使用本版平台进程，请重启平台。
