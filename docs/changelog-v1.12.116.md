# KeePlus / auto-dba v1.12.116

相对 [v1.12.115](changelog-v1.12.115.md)。实例总览里 PostgreSQL 的大约总量和数据使用率按云上购买磁盘计算，被授权实例也能对上别的租户名下的云磁盘。无 Agent 协议变更。无表结构变更。

## 实例总览

- PostgreSQL 的大约总量只取已关联云资产的购买磁盘。同一云实例有多条记录时，取同步时间最新且容量大于 0 的一条。没有云磁盘时大约总量为空，不再用已用存储除以监控使用率反推。
- 有云磁盘且已采到已用存储时，数据使用率改为已用存储除以这块容量。没有云磁盘时仍用云监控最近值。
- 匹配云磁盘时不按云清单的租户过滤。优先用平台实例上的云实例 ID，这样别的租户授过来的实例也能对上购买容量。
