# KeePlus / auto-dba v1.12.96

相对 [v1.12.95](changelog-v1.12.95.md)。终端会话失败时写明主机、用户和私钥，平台用 Go 拨 SSH 时 RSA 私钥兼容只收 `ssh-rsa` 的旧 sshd。CDC 建任务的源库可以过滤和手输，表映射的同步模式与目标表同一行。无 Agent 协议变更，无表结构变更。

## 终端与 SSH

- 会话已失败或超过最长存活时间时，先升级 WebSocket，再把原因写进终端。文案带主机、用户和私钥路径，并说明这不是平台登录过期。页面红条不再把「一次都没连上」说成登录失效。
- 打开终端前打印即将使用的用户、主机、端口和私钥路径。窗口标题带上私钥文件名。
- 平台用 Go 拨 SSH 时，RSA 私钥同时提供 `rsa-sha2-256`、`rsa-sha2-512` 和 `ssh-rsa`。只收旧算法的 sshd 可以连上。这影响 Agent 下发、备份和集群拨号。系统 `ssh` 打开的网页终端本身不走这条签名。
- 启动和热加载配置时，日志打出已落地私钥的算法和 SHA256 公钥指纹，不含私钥内容。Nacos 命名空间是 public 时提示：未单独指定命名空间的进程会读同一份配置。

## CDC

- 源库下拉改为框内过滤。输入后按回车，列表里没有的库名可以直接用。关闭下拉或更换源实例时清空过滤。
- 表映射里同步模式和目标表放在同一行，目标表名输入框加宽。
