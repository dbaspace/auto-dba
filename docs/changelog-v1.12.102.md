# KeePlus / auto-dba v1.12.102

相对 [v1.12.101](changelog-v1.12.101.md)。同步列表的主机列改为展示该库已登记的绑定域名。采集不再把实例域名列表拿去拨号。重启心跳改回连接主机。无 Agent 协议变更，无表结构变更。

## 同步槽

- 列表「实例(主机:端口)」和主机筛选使用该库自己的绑定域名。先取库的 domains，没有再取库标签 `domain=`。对不上或库没有绑定时留空，不回退连接主机，也不用实例域名列表。槽记录里的连接主机不变，重启查找仍用它。
- 采集优先拨连接主机的第一段。没有连接主机时，才用实例标签里第一条 `domain=`。实例域名列表、`domain_name` 和库绑定域名不参与采集，同一地址只采一次。覆盖旧槽时的别名也只含连接主机和标签 `domain=`。
- 重启心跳按连接主机拨号，不再按库登记域名拨号。没有连接主机时失败，提示未配置连接主机。
