# KeePlus / auto-dba v1.12.88

相对 [v1.12.87](changelog-v1.12.87.md)。工单详情在审核完成前自动刷新；查询页可点选同名库环境；建库审批人收窄到指定范围。无 Agent 协议变更，无表结构变更。

## 工单

- 工单详情在待审批、已通过、执行中时，每 3 秒静默刷新。审核通过并执行完成后，提交人打开的页面会更新状态，不必手动刷新。
- 已执行、失败、驳回、取消或终止后停止刷新。页签切走或浏览器在后台时不请求。

## 数据库查询

- 同名库有多个环境时，点击环境标签可直接选目标环境。右侧箭头仍按顺序切到下一个环境。

## 建库

- 建库审批人只保留 admin、dba 租户用户、`sync_default_approver` 和超级审核白名单。提交、转交和审批都按这个范围校验。
- 数据导出的 DBA / 安全审批人仍使用本租户候选人，不受建库范围影响。

## 打包与发版

```bash
STAMP=v1.12.88 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.88 -m "v1.12.88"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 行为，已下发的 Agent 不必为这个版本重装。
