# KeePlus / auto-dba v1.12.110

相对 [v1.12.109](changelog-v1.12.109.md)。云资源对账冲突时说明是哪个云账号不一致，同步时把实例云账号改到清单账号。PostgreSQL 冻结年龄的知识库补上视野阻塞和回卷处理。无 Agent 协议变更，无表结构变更。

## 云资源对账

- 对账列在冲突时写出原因：实例云账号和本条清单账号不同，或同一个云实例 ID 出现在多个云账号下。
- 同步碰到唯一云实例但账号不同时，把实例的云账号改成这条清单的账号，再标成已关联。
- 默认租户的云账号按连接主机对照全部租户的实例。其它租户只对照自己的实例。实例上同步云信息时，本租户清单没有对上，才再查默认租户。

## PostgreSQL 知识库

- 事务冻结年龄偏高和顶到回卷线的案例改为按 `xid_age`、`datfrozenxid`、复制槽和 idle in transaction 说明原因，并给出只读 `pg_class` 查最老表、解除视野后再 `VACUUM (FREEZE)` 的步骤。
- 「冻结」「冻结高」「回卷」「datfrozenxid」可以检索到这两组案例。
