# KeePlus / auto-dba v1.12.91

相对 [v1.12.90](changelog-v1.12.90.md)。初始化同步的源端改为域名管理；连接器可授权、可批量划拨；Kafka 改为批量只读授权；SQL 执行器显示运行状态。无 Agent 协议变更，无表结构变更。

## CDC

- 初始化同步第 1 步的源端下拉改为「资源配置 / 域名管理」里、当前环境和源引擎可见的域名。标签为「域名:端口 — 实例名」。没有域名记录的实例不再出现。
- 选中后仍用关联实例拉库表。Debezium 拨号地址写成所选域名。

## 连接器与 Kafka

- 租户授权和资源申请增加「连接器」。列表、预检和创建任务会带上授权给当前租户或当前用户的连接器。修改和删除仍只限归属租户。
- 租户模式下，连接器可勾选后批量划到目标租户，不连带改 Kafka 实例。
- Kafka 列表去掉行内「指定租户」。租户模式下勾选后「批量授权」，只给目标租户只读，实例、库和账号仍留在原租户。其它实例类型的行内「指定租户」保留。

## 平台 Agent

- SQL 执行器增加运行状态。打开页面或点「刷新状态」时批量探活，不改启用状态。

## 打包与发版

STAMP=v1.12.91 ./scripts/pack_release.sh all
