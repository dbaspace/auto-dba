# KeePlus / auto-dba v1.12.152

相对 [v1.12.151](changelog-v1.12.151.md)。拓扑视图先返回连接表，连接池改为瞬时聚合，避免整页等待 7 天曲线。无 Agent 协议变更，无表结构变更。

## SQL 洞察

- 查询拓扑时先返回连接数和 Pod。有 Pod 的行再单独取连接池，这些列显示「查询中」，失败只追加提示，不丢掉连接行。
- 连接池不再拉取最近 7 天的全部采样点。当前值、7 日峰值和空闲占比改为瞬时聚合，Prometheus 每个 Pod 只返回一个数。聚合失败时退回步长 1 小时的区间查询。同一组 Pod 的结果缓存 3 分钟。
- 分析规则、表格列和导出与上一版相同。

## 打包与发版

```bash
STAMP=v1.12.152 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.152 -m "v1.12.152"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。归档仍依赖 v1.12.145 起的 SQL 执行器；执行器已是 v1.12.145 或本版包时，不必为这个版本重装。若执行器仍是 v1.12.144 及更早，须用 v1.12.145 或本版包重下发。其它 Agent 若仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。本版拓扑查询要使用本版平台进程，请重启平台。
