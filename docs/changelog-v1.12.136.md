# KeePlus / auto-dba v1.12.136

相对 [v1.12.135](changelog-v1.12.135.md)。StarRocks 登记按监控域名复用已有实例；FE 管理不再手填账号密码，SR 控制台改用实例凭据。Redis 工单审核人与云 PostgreSQL 同一池。海豚控制台不再改写平台登录用户。无表结构变更，无 Agent 协议变更。

## StarRocks 实例

- 登记已有集群时，把「从监控目标导入」里选中的 domain 一并提交。
- FE 地址对不上时，再用这个域名和监控任务上已有的 `domain`，去对实例的域名列表或 `domain=` 标签。对上就补 `sr-cluster=` 标签，不再新建，也不改所属租户和密码。
- 查询端口仍要一致，`8030` 不会并进 `9030`。已经多出来的行不会自动删除。

## FE 管理与 SR 控制台

- FE 管理新建、编辑和从监控同步不再填写或修改用户名、密码。列表去掉密码列和「待补凭据」。
- 需要登录时，用 FE 记录上的域名去对本租户 StarRocks 实例的域名或 `domain=` 标签，取该实例的账号和连接密码。
- SR 控制台、登记时的「从实例获取密码」和目录探测都走这套匹配。对不上时提示「未匹配到实例账号」，不再使用 FE 管理里保存的旧密码。

## Redis 工单

- 审核人增加平台管理员、dba 租户活跃成员和全局审核白名单，与云 PostgreSQL 工单相同。
- 这些人可以审批 Redis 工单，不要求是当前租户成员。实例上原来的审批人仍然可用。

## 海豚控制台

- 平台管理员在海豚管理页可以看到各租户的环境。配置页和普通成员仍只看当前租户。
- 嵌入页把海豚的登录用户写到 `ds-embed-user`，不再覆盖平台自己的 `localStorage.user`。

## 打包与发版

```bash
STAMP=v1.12.136 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：

```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。StarRocks 登记、FE 管理和 SR 控制台要使用本版平台进程，请重启平台。已有元库不用补表。
