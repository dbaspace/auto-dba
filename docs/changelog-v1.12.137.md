# KeePlus / auto-dba v1.12.137

相对 [v1.12.136](changelog-v1.12.136.md)。工单列表不再整表读取 SQL 正文。登记已有 StarRocks 集群时，按所选 domain 从当前用户能打开的实例取账号和密码。无 Agent 协议变更。

## 工单列表

- 列表只查展示字段，不再读取每条工单的 SQL 正文。详情页仍返回完整 SQL。
- 环境和数据库类型改为一次关联实例表取出。实例对不上、这两项仍为空时，只读正文前 4096 个字符来补。
- 跨租户的平台资源申请、指派工单和权限申请也走这套摘要查询。可见范围、筛选和前端分页不变。
- 元库增加 `tbl_issues(tenant_id, created_at)` 索引，列表按创建时间排序时可以走索引。

## StarRocks 登记

- 「从实例获取密码」「探测 FE 角色与目录」「仅探测目录」按所选 domain 取账号和密码。
- 候选是当前用户能打开并测试连接的 StarRocks 实例：本租户，加上授权实例、本租户库所在实例、访问域名可达的实例。平台管理员在审计会话中可以看全部实例。
- 匹配域名、域名列表、`domain=` 标签和连接主机，比较前去掉协议和端口。命中后填入该实例的账号和密码，不改所属租户。
- 对不上时提示「未匹配到实例账号」。对上了但没存密码时提示「已匹配实例但未保存密码」。这两种情况都不再用空密码连接 FE。
- FE 管理和 SR 控制台仍只读本租户实例。

## 打包与发版

```bash
STAMP=v1.12.137 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：

```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。工单列表和 StarRocks 登记要使用本版平台进程，请重启平台。已有元库补上下面这条索引后再重启：

```sql
CREATE INDEX IF NOT EXISTS idx_issues_tenant_created ON tbl_issues(tenant_id, created_at DESC);
```
