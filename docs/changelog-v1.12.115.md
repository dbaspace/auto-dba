# KeePlus / auto-dba v1.12.115

相对 [v1.12.114](changelog-v1.12.114.md)。实例总览显示别的租户授过来的实例。云慢日志去掉页内筛选，列表可按库过滤、按耗时排序。同步列表和迁移设置按角色授权按钮。无 Agent 协议变更。无表结构变更。

## 实例总览

- 总览除本租户实例外，并入授给当前租户的实例、被授数据库的父实例、被授域名的父实例。已在列表里的不重复。平台管理员看全量时不再合并。刷新采集走同一份列表。
- PostgreSQL 的大约总量优先用已关联云资产的磁盘容量。同一实例有多条云记录时，取同步时间最新且容量大于 0 的一条。没有关联时仍用已用存储除以使用率。
- StarRocks 的数据使用率改为各 BE 数据存储之和除以数据盘总大小。悬停显示整盘最高使用率和对应 BE。低于 1% 的使用率保留一位小数。

## SQL 洞察

- 云慢日志去掉页顶的库名、SQL、最小耗时和查询。慢 SQL 列表的库列按当前结果多选过滤，耗时列可升序或降序。导出跟随库过滤后的行。
- 页签上方的实例下拉固定 360px，时间范围固定 380px，查询和重置紧跟在后面。
- 去掉 SQL 洞察页签栏上的设置按钮。配置中心里的 SQL 洞察设置页保留。

## 同步与迁移

- 同步列表的手动采集、批量重启、查看操作日志、批量删除各自一条操作权限，挂在同步列表下面。没有对应权限时按钮不出现，接口也会拒绝。已有该页面的角色首次启动会带上这四项。
- 迁移设置单独一条操作权限。没有权限时不显示入口，设置页提示无权限，保存和测试对象存储会被拒绝。

## 查询

- 查询窗口支持撤销和重做，补全和格式化也记入这一步。
- 选中 SQL 后复制能拿到原文。
