# KeePlus / auto-dba v1.12.122

相对 [v1.12.121](changelog-v1.12.121.md)。实例总览的主机列表显示应用名，过滤后分页固定在表格底部。无 Agent 协议变更。无表结构变更。

## 实例总览

- 主机列表增加「应用」列，取主机标签里第一条非空 `app=`（键不区分大小写）。导出 CSV 同步带上应用名。名称或地址过滤也匹配应用名。
- 应用名来自「从监控同步」写入的标签。没有 `app=` 时显示为「—」。
- 按条件过滤后，分页条固定在表格底部，不再被页面裁掉。筛选变化时回到第 1 页。主机仍默认每页 10 条。
