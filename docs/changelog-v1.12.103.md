# KeePlus / auto-dba v1.12.103

相对 [v1.12.102](changelog-v1.12.102.md)。同步列表的主机列改为该库自己的绑定域名。CDC 任务在源端实例缺失时按地址找回，源端没探测到时不再把 Publication 和复制槽显示成已有结果。无 Agent 协议变更，无表结构变更。

## 同步槽

- 「实例(主机:端口)」显示已登记库上的绑定域名，并带上槽的端口。`db_ai` 这类库显示 `pg.test.restosuite.ai:5432`，不显示实例连接主机 `10.100.112.10`。
- 只读该库自己的 domains。domains 为空时才用库标签 `domain=`。一个库有多个主机名时用逗号隔开。实例域名列表里多出来的名字，例如没有绑到这个库的 `pg.saler.test.restosuite.ai`，不会出现在这一列。
- 没有绑定域名时这一格留空。槽记录里的连接主机不变，采集和重启仍用它。

## CDC 源端

- 链路状态先用任务上的源端实例。实例不存在时，按任务生效地址匹配实例的连接主机、主域名和附加域名。唯一命中才用来探测；没有命中或命中多台时不猜测，页面说明原因。这次探测不写回任务。
- 源端实例对不上，或源库连不上时，Publication 和复制槽标成未探测，不再显示成不存在或 inactive。
- 修复源端地址可以填域名或 IP。任务还没绑实例时，按填写的地址找回唯一实例并写回这条任务的源端实例。地址只改这一条任务，不改实例上其它库共用的连接主机。
