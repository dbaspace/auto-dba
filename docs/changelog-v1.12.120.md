# KeePlus / auto-dba v1.12.120

相对 [v1.12.119](changelog-v1.12.119.md)。云主机的磁盘按块展示，并补上系统盘和后挂的多块数据盘。实例总览可以看主机的云规格和数据盘使用率。无 Agent 协议变更。无表结构变更。

## 云资源 · 主机

- 同步时按地域查询云硬盘，补上 `DescribeInstances` 里经常为空的系统盘大小，并收齐后来单独挂上的多块数据盘。同一块盘只计一次。主机接口里对不上云硬盘、且有大小的本地盘仍保留。
- 云硬盘查询失败时，这次同步仍完成，磁盘只用主机接口里已有的大小。
- 「磁盘 GB」逐行写出系统盘和每一块数据盘的大小、类型，不再显示一个加总数字。库里的合计仍给实例总览和变配使用。

## 实例总览 · 主机

- 主机页展示云上状态、CPU、内存、系统盘，以及每一块数据盘的大小。多块数据盘用顿号分开，悬停可看合计。
- 数据盘使用率来自 node_exporter 的文件系统用量，不含 `/`、`/boot`、`/boot/efi`。达到 80% 标成「数据盘偏高」。未关联云主机的行单独标出。

STAMP=v1.12.120 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，已下发的 Agent 不必为这个版本重装。云主机磁盘和实例总览要使用本版平台进程与前端，请重启平台并刷新页面。云资源里对主机再点一次「立即同步」后，磁盘才会按块更新。只读密钥需要云硬盘查询权限 `cbs:DescribeDisks`。
