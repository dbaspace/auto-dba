# KeePlus / auto-dba v1.12.107

相对 [v1.12.106](changelog-v1.12.106.md)。CDC 修复源端时，地址下拉同时显示实例名，并可按域名、IP 或实例名筛选。无 Agent 协议变更，无表结构变更。

## 修复源端

- 地址候选项来自当前源实例的主域名、连接主机和域名列表。每一项写成「地址 — 实例名」，重复地址只保留一条。
- 输入时按地址和实例名一起过滤。仍可直接填写不在列表里的域名或 IP。修复仍只改这一条任务的源地址，不改实例上其它库共用的 Host。

## 打包与发版

```bash
STAMP=v1.12.107 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.107 -m "v1.12.107"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，已下发的 Agent 不必为这个版本重装。刷新页面即可使用修复源端的地址下拉。
