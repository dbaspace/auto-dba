# KeePlus / auto-dba v1.12.146

相对 [v1.12.145](changelog-v1.12.145.md)。通用查询打字不再等整页画完。Kafka Topic 不能在页面上直接删除。SQL 洞察增加拓扑视图。无 Agent 协议变更，无表结构变更。

## 查询

- 通用查询的 SQL 框先在编辑器里显示刚敲的字，高亮只跟这段文本走。页签和本机保存延后约 300 毫秒。运行、失焦、切页签和离开页面时立刻保存，Ctrl/⌘+Enter 执行的是当前文本。
- 补全延后约 120 毫秒。弹出层关着时不再为补全重绘页面，只在弹出层开着时测量光标。Ctrl/⌘+Space 仍马上补全。
- 撤销、重做、美化、注释、收藏，以及从库树填入查询，仍替换编辑器里的全文。

## Kafka

- 删除 Topic 改为提交 Kafka 工单，审批通过前不会删除。直接调用删除接口会拒绝。
- 查看消息、分区和日志需要「查看 Topic」。查看配置需要「查看配置」。提交删除工单需要「删除 Topic」。个人访问令牌拉消息仍不要求页面上的查看权限。
- 重启平台后，已有「Kafka 查询」权限的角色会带上这三项。没有该父菜单的角色不会自动获得。

## SQL 洞察

- 新增「拓扑视图」页签。对 PostgreSQL 实例统计最近 5 分钟有活动的客户端连接，并用智能分析里配置的 Prometheus 把地址对应到 Pod。仅支持 PostgreSQL。
- 页签权限为「拓扑视图」。重启平台后，已有 SQL 洞察菜单的角色会带上该页签。

## 账号

- 账号列表按当前筛选结果分页，默认每页 10 条，可改为 20、30、50、100。更换筛选条件后回到第 1 页。

## 打包与发版

```bash
STAMP=v1.12.146 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.146 -m "v1.12.146"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。归档仍依赖 v1.12.145 起的 SQL 执行器；执行器已是 v1.12.145 或本版包时，不必为这个版本重装。若执行器仍是 v1.12.144 及更早，须用 v1.12.145 或本版包重下发。其它 Agent 若仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。本版查询、Kafka 权限和拓扑视图要使用本版平台进程，请重启平台。
