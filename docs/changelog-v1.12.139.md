# KeePlus / auto-dba v1.12.139

相对 [v1.12.138](changelog-v1.12.138.md)。海豚管理不再因为嵌入脚本反复改页面而卡住。登记已有 StarRocks 集群时，每台 FE 各自探测软件目录。无 Agent 协议变更。

## 海豚管理

- 打开海豚管理后，环境框不再反复弹出当前环境，页面可以点击和刷新。
- 环境选项没变时不再重写下拉框。用户正在选择环境时不改它的值。
- 顶栏折叠按钮改为隐藏，不再删掉后被海豚加回来。柱状图只调整一次。侧栏隐藏、去水印和 40px 顶栏保持不变。

## StarRocks 目录探测

- 登记已有集群时，表单里的每台 FE 各自连接 `:9030`，读取该台的 `meta_dir` 和 `sys_log_dir`。软件根按主机回填。
- 推断结果是全局默认目录的截断（例如 `/home/dorisdb` 相对 `/home/dorisdb_base`）时不写入，避免升级替换错目录。无法确定时清空该台已填的软件目录。
- FE 与全局默认相同时节点留空，继续走全局配置。BE 软件目录按各台 `/varz` 的 `sys_minidump_dir` 或 `sys_log_dir` 填写，数据目录仍用 `storage_root_path`。

## Node Agent

- 列表搜索同时匹配 Agent 名称、主机名、地址和域名。下发记录使用同一关键字过滤。

## 打包与发版

```bash
STAMP=v1.12.139 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.139 -m "v1.12.139"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。海豚管理和目录探测要使用本版平台进程，请重启平台。
