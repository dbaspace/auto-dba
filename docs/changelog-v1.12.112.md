# KeePlus / auto-dba v1.12.112

相对 [v1.12.111](changelog-v1.12.111.md)。SQL 洞察增加慢日志同步监控，云慢日志可导出当前结果。单页云接口超时不再让整次定时任务失败。实例列表按时间索引计数，避免页面 30 秒超时。无 Agent 协议变更。元库为慢日志游标补入库条数。

## 慢日志

- SQL 洞察去掉实例标签，在「云慢日志」后增加「同步监控」。每张卡片按采集、Kafka（或直写元库）、入库展示最近一小时写入条数，箭头上显示游标、延迟、完整性和落后。可按名称、主机或状态搜索，按正常、告警、失败筛选，并显示记录条数。分页 10/20/30/50/100。
- 云慢日志 SQL 固定单行，点「查看」弹出全文。去掉「同步设置」和「立即同步」。列表和统计可把当前结果导出为 CSV。分页增加 10/20/30/50/100。
- 某一轮没有新慢日志时，不再把已采集条数清零。最近一小时条数按 `log_time` 文本比较，走已有时间索引，实例列表不再因全表扫描超过页面 30 秒。
- `DescribeSlowQueryList` 超时改为 120 秒，读响应失败带上接口名，这种超时再试一次。单个实例重试后仍超时，只记在该实例游标上，同步监控显示失败。定时任务不再整次失败，也不再发这条整任务通知。其它错误仍会让任务失败。

## 查询

- 查询窗口 `Ctrl+A` 全选 SQL，`Esc` 取消选中。
