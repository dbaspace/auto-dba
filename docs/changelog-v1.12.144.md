# KeePlus / auto-dba v1.12.144

相对 [v1.12.143](changelog-v1.12.143.md)。域名管理的 Redis 页可以一次给多条域名追加或撤销审核人。单条编辑仍可用。无 Agent 协议变更，无表结构变更。

## Redis 域名审核人

- Redis 页勾选域名后可以批量设置审核人、批量撤销审核人。按钮只出现在 Redis 页，仍要有域名编辑权限。
- 批量设置从这些域名所属租户的活跃成员里选，追加到各域名现有名单，不覆盖。不是该租户成员的名字会被忽略；这次追加时，名单里已经不是成员的名字也会被拿掉。
- 批量撤销从所选域名现有审核人里选。某个域名上没有这个人则跳过该域名，名单可以撤空。
- 必须勾选同一租户下的 Redis 域名。类型不是 Redis，或跨租户，整批拒绝。平台管理员可以改任意租户；其他用户只能改本租户。
- 一键同步仍不写入、不覆盖域名审核人。
