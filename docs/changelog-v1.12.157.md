# KeePlus / auto-dba v1.12.157

相对 [v1.12.156](changelog-v1.12.156.md)。慢 SQL 周报按环境、业务线和库生成 HTML，定时以附件发送，并可在平台查看。

## 慢 SQL 周报

- SQL 洞察设置增加「慢 SQL 周报」。按环境、业务线、实例和库配置收件人，可预览、立即发送。实例和库可在下拉内过滤、全选、反选。
- 发送时间不在规则里配置，统一用定时任务 `cloud.slow_report`。默认每周一 09:00（`0 9 * * 1`）。已存的 `60s` / `1m` 会在启动时改成该 Cron。
- 周报按环境切换。指标含本周与上周次数、日均、CPU 峰值、P99、新增和未再出现的模板数。占总请求比固定为「—」。排名含库，可按库过滤，SQL 摘要后可查看全文。
- 邮件正文只保留下载说明，周报 HTML 作为附件。诊断 → 性能诊断下可打开已生成周报。
- 多个平台实例共用同一云实例时，规则必须填写库名，否则不发送。
- 已有库启动时补齐 `tbl_cloud_slow_reports`、`tbl_cloud_slow_report_mails`。归档告警表也会在跳过全量迁移时创建，避免每分钟报缺表。
- 归档概览的归档量改为已删除行数合计。

## 打包与发版

```bash
STAMP=v1.12.157 ./scripts/pack_release.sh all
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议，不必仅为本次重下发执行器。周报和定时任务在平台侧，请重启平台。
