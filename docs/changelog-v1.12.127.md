# KeePlus / auto-dba v1.12.127

相对 [v1.12.126](changelog-v1.12.126.md)。数据迁移的审核人改为与建库同一审批人池，不再要求加入任务租户。无表结构变更，无 Agent 协议变更。

## 数据迁移

- 新建、重新提交、转移审核人时，审核人可以是 `admin`、`sync_default_approver`、全局审核白名单或 DBA 租户活跃成员。不在池中会提示须为这四类用户。
- 不再因为「不是该租户的活跃成员」拒绝，也不再按迁移设置名单或源实例、库的审批人名单拦截。未选审核人时使用池中第一人。
- 新建迁移任务和工单转移审核人的下拉，与建库使用同一名单。迁移设置页里的审核人名单仍保留，只是创建和转移不再用它拦人。

## 打包与发版

```bash
STAMP=v1.12.127 ./scripts/pack_release.sh all
# 本地标签（本发版未 push / 未发 GitHub Release）：
# git tag -a v1.12.127 -m "v1.12.127"
```

部署见 [deploy.md](deploy.md)。一体包含本版构建的全部 Agent 二进制。本次未改 Agent 协议。已经用 v1.12.124 及以后包下发过的 SQL 执行器不必为这个版本重装；若执行器仍是 v1.12.123 及更早，须用 v1.12.124 或本版包重下发。迁移审核人要使用本版平台进程与前端，请重启平台并刷新页面。
