# KeePlus / auto-dba v1.12.93

相对 [v1.12.92](changelog-v1.12.92.md)。同步列表的采集改回连接主机，每个地址只采一次；批量重启在本地没有 CDC 任务时使用采集记下的连接器。不改 CDC 同步任务的创建、源端域名和执行。无 Agent 协议变更，无表结构变更。

## 同步列表

- 采集复制槽只用实例连接主机，不再用域名或标签 `domain=`。同一连接主机和端口只连一次。没有连接主机的实例跳过并说明原因。下次采集按槽名把记在域名上的槽改回连接主机。
- 批量重启在本地 CDC 任务对不上时，改用采集时记下的连接器名称和地址，不再整批跳过。
- 重启前写心跳只拨该库已登记的域名。库没有域名时这一条失败，不回退连接主机，也不改实例连接主机和 CDC 任务里的源端地址。
